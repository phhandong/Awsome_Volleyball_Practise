# 排球二传战术板 · 3D 传球路线设计（第一版）

网页端 3D 排球战术工具：以二传视角设计传球路线，内置一/二/三/负节奏与背传五种风格的推荐方案。
架构参考 [sunny30119/volleyball-tactics](https://github.com/sunny30119/volleyball-tactics)（Vite + React + three/R3F + zustand，逻辑/呈现分离，参数化抛物线闭式解）。

## 启动

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest：轨迹求解与方案评分单测
npm run build      # 产物构建
```

## 第一版功能

- **三维可移动视角**：自由旋转/缩放/平移 + 全景/底线/边线/俯视四个预设机位（阻尼过渡、手动打断）
- **二传第一人称**：相机锁定二传头部（1.78m），FOV 75°（垂直）≈真人双目视野；飞行/击飞阶段自动跟球、静止看传球点；拖拽环视、`F` 回正、`Esc` 退出；HUD 实时显示飞行时间/球速/仰角/目标区
- **传球参数编辑**：三种模式互切——按弧顶高度（默认）/ 按飞行时间 / 按球速+仰角（低弧/高弧）；击球高度支持滑杆、面板预设（快攻 2.55 / 标准 2.8 / 超手 3.05 / 后排 3.25）与 3D 内竖直拖拽击球点小球；拖动/切换攻手时击球点自动跟随平移；实时读数（球速、仰角、方向角、弧顶、离网距离、过网余量红绿提示）
- **球动画与击飞弧线**：完整回合 = 二传举球出手 → 传球抛物线（自转+拖尾）→ 攻手助跑起跳、举手触球 → **红色虚线击飞弧线**飞向对方场地 → 落地定格；播放/暂停/回开头/0.25×–2× 变速/进度拖动
- **五风格推荐方案**：一节奏（快球）、二节奏（半高）、三节奏（高球拉开）、负节奏（远网调整高球）、背传（背后组织），每风格按"离网距离/攻手到位/出手仰角/弧线安全"评分取 Top3，点击即套用预览
- **高质感视觉**：程序化贴图的蓝黄白 18 片排球、蓝地胶/木地板双主题场地、网孔球网+红白标志杆、关节可动的低多边形运动员（队服号码、自由人异色、选中高亮环）、软阴影+地板反射+ACES 色调映射，支持高画质/流畅切换
- **传球质量检查（警示系统）**：依据二传教学与排球规则对当前方案实时体检——离网距离、人球节奏（Δ 时间+助跑步数）、击球高度 vs 攻手摸高、弧顶与节奏匹配、击飞过网余量、出手高度、二传—目标距离、**规则违例**（自由人进攻/后排前区扣高于网）；3D 场景内浮动距离尺/高度尺/理想区色带 + 警示色 chip（🟢优/🟡注意/🔴风险），面板给出预检清单与综合评分，目标环随风险等级变色
- **存档**：站位与路线参数一键导出/导入 JSON

## 操作速查

攻手腾空时沿助跑方向持续前移：前排默认水平速度 1.3m/s，后排双脚起跳默认 2.2m/s；起跳点按空中位移反推，保持手球接触。落地后再制动减速。极短助跑或贴网球会在离地前降低水平速度，质量图例显示实际取值。研究来源和模型限制见 `CONTRACTS.md`。

| 操作 | 方式 |
|---|---|
| 旋转/缩放/平移视角 | 左键拖动 / 滚轮 / 右键拖动 |
| 移动球员、调整传球目标 | 直接拖拽场上球员或黄色目标环 |
| 切换预设机位 | 面板"视角与画质"，重按同按钮可重播过渡 |
| 二传第一人称 | 面板按钮进入，`F` 回正看球，`Esc` 退出 |
| 播放/变速/任意查看 | 动画播放区，拖进度条即暂停逐帧查看 |

## 设计说明

- **轨迹模型**：二传球 = 重力抛物线（g=9.81，无空气阻力）。按弧顶为闭式解，按球速扫描+二分求根（低/高弧两解）。详见 `CONTRACTS.md`。
- **评分规则**：离网理想区前排 0.5–1.2m / 后排进攻 3.3–7.2m；攻手 4.5m/s 到位性；仰角 22°–58°；弧顶 2.6–5.2m 且过网余量 ≥0.2m。
- **负节奏**采用参考项目惯例：远网调整高球（比三节奏更慢更高），变体可在 `logic/presets.ts` 的 `STYLE_SPECS` 中调整。
- **视觉资产**全部程序化生成（canvas 贴图 + 几何拼装），无外部资源依赖，可离线运行。
