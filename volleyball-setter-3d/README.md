# 排球进攻战术板 · 3D 二传与攻手排练

网页端 3D 排球战术工具：以二传视角设计传球路线，内置一/二/三/负节奏与背传五种风格的推荐方案。
架构参考 [sunny30119/volleyball-tactics](https://github.com/sunny30119/volleyball-tactics)（Vite + React + three/R3F + zustand，逻辑/呈现分离，参数化抛物线闭式解）。

## 启动

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest：轨迹求解与方案评分单测
npm run build      # 产物构建
```

## Vercel 部署

在 Vercel 导入仓库后，将 Root Directory 设置为此目录（仓库内的 `volleyball-setter-3d`），并使用以下设置：

- Framework Preset：`Vite`
- Node.js Version：`24.x`（已在 `package.json` 的 `engines` 中指定）
- Install Command：`npm ci`
- Build Command：`npm run build`
- Output Directory：`dist`

提交 `package.json`、`package-lock.json` 和 `.npmrc` 后重新部署。首次修复部署时取消勾选使用现有 Build Cache，以免复用旧依赖。Vercel 支持通过 [`engines.node` 指定 Node.js 版本](https://vercel.com/docs/functions/runtimes/node-js/node-js-versions)。

构建器的系统专用包由 Vite / Rolldown 的可选依赖自动选择，不要将 `@rolldown/binding-win32-*` 添加为项目的直接依赖，否则会影响 Linux 部署。

## 第一版功能

- **三维可移动视角**：自由旋转/缩放/平移 + 全景/底线/边线/俯视四个预设机位（阻尼过渡、手动打断）
- **二传第一人称**：相机锁定二传头部（1.78m），FOV 75°（垂直）（屏幕上的近似视角，非实测人眼或双目重建）；飞行/击飞阶段自动跟球、静止看传球点；拖拽环视、`F` 回正、`Esc` 退出；HUD 实时显示飞行时间/球速/仰角/目标区
- **传球参数编辑**：三种模式互切——按弧顶高度（默认）/ 按飞行时间 / 按球速+仰角（低弧/高弧）；击球高度支持滑杆、面板预设（快攻 2.55 / 标准 2.8 / 超手 3.05 / 高点 3.25）与 3D 内竖直拖拽击球点小球；拖动/切换攻手时击球点自动跟随平移；实时读数（球速、仰角、方向角、弧顶、离网距离、过网余量红绿提示）
- **球动画与击飞弧线**：完整回合 = 二传举球出手 → 传球抛物线（自转+拖尾）→ 攻手助跑起跳、举手触球 → **红色虚线击飞弧线**飞向对方场地 → 落地定格；播放/暂停/回开头/0.25×–2× 变速/进度拖动
- **五风格推荐方案**：一节奏（快球）、二节奏（半高）、三节奏（高球拉开）、负节奏（远网调整高球）、背传（背后组织），每风格按"离网距离/攻手到位/出手仰角/弧线安全"评分取 Top3，点击即套用预览
- **高质感视觉**：程序化贴图的蓝黄白 18 片排球、蓝地胶/木地板双主题场地、网孔球网+红白标志杆、关节可动的低多边形运动员（队服号码、自由人异色、选中高亮环）、软阴影+地板反射+ACES 色调映射，支持高画质/流畅切换
- **传球质量检查（警示系统）**：依据二传教学与排球规则对当前方案实时体检——离网距离、人球节奏（Δ 时间+助跑步数）、击球高度 vs 攻手摸高、弧顶与节奏匹配、击飞过网余量、出手高度、二传—目标距离、**规则违例**（自由人进攻/后排前区扣高于网）；3D 场景内浮动距离尺/高度尺/理想区色带 + 警示色 chip（🟢优/🟡注意/🔴风险），面板给出预检清单与综合评分，目标环随风险等级变色
- **存档**：站位与路线参数一键导出/导入 JSON

## 操作速查

攻手腾空时沿助跑方向持续前移：前排默认水平速度 1.3m/s，后排双脚起跳默认 2.2m/s；起跳点按空中位移反推，保持手球接触。落地后再制动减速。极短助跑或贴网球会在离地前降低水平速度，质量图例显示实际取值。研究来源和模型限制见 `CONTRACTS.md`。

| 操作 | 方式 |
|---|---|
| 旋转/缩放/平移视角 | 左键拖动 / 滚轮 / 右键拖动 |
| 移动球员、调整传球目标 | 直接拖拽场上球员或黄色目标环 |
| 切换预设机位 | 面板"视角与画质"，重按同按钮可重播过渡 |
| 二传第一人称 | 面板按钮进入，`F` 回正看球，`Esc` 退出 |
| 播放/变速/任意查看 | 动画播放区，拖进度条即暂停逐帧查看 |

## 设计说明

- **轨迹模型**：二传球 = 重力抛物线（g=9.81，无空气阻力）。按弧顶为闭式解，按球速扫描+二分求根（低/高弧两解）。详见 `CONTRACTS.md`。
- **评分规则**：离网理想区前排 0.5–1.2m / 后排进攻 3.3–7.2m；攻手 4.5m/s 到位性；仰角 22°–58°；弧顶 2.6–5.2m 且过网余量 ≥0.2m。
- **负节奏**采用参考项目惯例：远网调整高球（比三节奏更慢更高），变体可在 `logic/presets.ts` 的 `STYLE_SPECS` 中调整。
- **视觉资产**全部程序化生成（canvas 贴图 + 几何拼装），无外部资源依赖，可离线运行。

## 助跑与轮转身份

当前是右手扣球模型，默认三步 **左—右—左**；可选两步右—左、四步右—左—右—左。快球推荐自动选择两步。质量检查直接读取动画计划，检查实际地面距离、步序、助跑峰值、助跑时长、起跳脚前缘、腾空速度和时间余量。距离和最少时间参考范围属于排练参数，不是普适生理标准。

本轮 2/3/4 号位为前排，1/5/6 号位为后排。每人有独立号位，退到后场助跑不会变成后排。后排高球检查的是实际起跳脚不能碰三米线，允许起跳后进入前场击球或落地。号位编辑、正传/背传和助跑步数均保存在 JSON 中，兼容旧存档。

背传时二传背对目标方向；来球从身前上方落到双手，再连续送向头顶后方。播放栏“二传出手”可核对出手点与双手接触，“击球瞬间”可核对攻手手球接触。教学和规则来源见 [CONTRACTS.md](CONTRACTS.md)。

## 网页标识与显示名称

网页主名称为“排球进攻战术板”，标签页标题为“排球进攻战术板 · 3D 排练”，页内副标题为“3D 二传与攻手排练”。标签页和页内共用 `public/volleyball.svg` 蓝、黄、白排球标识；资源链接使用 Vite 的部署基础路径，支持子目录部署。

本工具是单页应用，无外部页面导航。全景、底线、边线、俯视为机位切换；从二传第一人称选择这些机位时会自动退出第一人称。推荐卡片的“起点距目标”指地面投影距离，实际助跑距离在“传球与助跑检查”中。地板号码为场地区域，球员本轮身份通过轮转号位单独设置。
