# 传球质量可视化 — 因素体系与警示呈现实施计划

## 一、调研结论：影响二传传球质量的因素（含量化标准）

结合中文教学资料与国际教练文献（来源见文末），归纳为 8 项**可计算**指标：

| # | 因素 | 教学依据 | 量化标准（系统采用） |
|---|---|---|---|
| 1 | **离网距离** | 太贴网会被拦/触网，太开攻手无法完整挥臂；共识"离网约 2–4 英尺（0.6–1.2m）"，中文教学 0.5–1m | 前排进攻 `[0.5, 1.2]m` 优；`<0.3` 红（贴网）；`[0.3,0.5)`/`(1.2,2.0]` 黄；负节奏用 `[2.2,4.6]`、后排攻 `[3.3,7.2]` |
| 2 | **人球节奏（人球关系）** | 国际教练共识：节奏由"二传出手时攻手还剩几步"定义——一节奏=最后一步起跳，二节奏=还差约2步，三节奏=提前启动 | Δ = 飞行时间 −（反应0.25s + 助跑距离/4.5m·s + 起跳0.18s）。`Δ<0` 红"球到人未到"；`0–0.05s` 绿"节奏吻合"；等球超过风格上限（一节奏0.15s/二节奏0.4s/三节奏0.8s/负节奏1.2s）黄"等球久、易被预判" |
| 3 | **击球高度 vs 攻手摸高** | 攻手应尽量在最高点击球；低于网口易被拦 | 摸高 = 站立举手 2.45m + 弹跳（副攻 0.85 / 主攻·接应 0.75 / 二传 0.65）。`>摸高+0.05` 红"超出最高击球点"；`[摸高−0.15, 摸高]` 绿"超手窗口"；`<2.3` 黄"击球点偏低易被拦"；前排扣球 `≤2.53`（网+0.1）黄"过网角度受限" |
| 4 | **弧顶高度与节奏匹配** | 弧线决定节奏：快球低平、高球高弧；弧顶偏离节奏特征=节奏失真 | 风格标准域：一节奏 2.55–2.95 / 二节奏 3.0–3.6 / 三节奏 3.5–4.5 / 负节奏 4.4–5.4 / 背传 2.7–3.5，域外黄"弧顶与所选节奏不符"；自由编辑（无风格）用 2.6–4.6 |
| 5 | **击飞过网余量** | 攻手击球后球必须明显过网 | 击飞线在网面处余量 `≥0.25` 绿 / `0.12–0.25` 黄"贴网" / `<0.12` 红"触网风险"（现有算法已保证 ≥0.12，仍实时显示） |
| 6 | **出手高度** | 教学要领：额前上方约一球距离出手（~2.2m+） | `[2.05, 2.5]` 绿；`<2.05` 黄"出手点偏低"；`>2.6` 信息"跳传出手" |
| 7 | **规则违例（硬警示）** | 排球规则：后排队员在前场区起跳、击球点整体高于网上沿且击球过网=违例；自由人任何位置不得进攻 | 攻手站位在后场（x>3）且击球点 x<3（前场）且接触高度>2.43 → 红"后排违例风险：需在进攻线后起跳"；攻手=自由人 → 红"自由人不得进攻" |
| 8 | **二传—目标距离**（辅助） | 长距离调整传球精度风险 | `<0.8m` 黄"分球空间不足"；`>7m` 黄"长传调整，精度风险" |

来源：[Volleyball Magazine — Setting Fundamentals](https://volleyballmag.com/volleyball-setting-fundamentals-hands-footwork-and-target/)、[USA Volleyball — Thoughts for Setters](https://usavolleyball.org/resource/thoughts-for-setters/)、[JVA — Setting Drills](https://jvavolleyball.org/drills-train-good-setting-habits/)、[Gold Medal Squared — Set Calls（节奏=剩余步数）](https://goldmedalsquared.com/)、[The Art of Coaching Volleyball — approach timing](https://www.theartofcoachingvolleyball.com/when-to-train-setters-on-jump-setting/)、[维基百科排球规则/后排违例三条件](https://zh.wikipedia.org/wiki/排球)、2025 高中体育背飞战术教学课件（节奏口令、最佳击球区）。

## 二、界面呈现设计

### 警示色规范（全局统一）
🟢 优 `#7ce6a5` · 🟡 注意 `#ffc83d` · 🔴 风险/违例 `#ff7a6e`；应用于 3D 图例、质检面板、目标环联动。

### 1. 3D 浮动图例（drei Html 标签 + 线条，随时可开关）
- **离网距离尺**：地面从网线到目标环的水平标尺（带端点刻度），浮动标签"离网 0.95m"按标准域着色；同时在地面绘制半透明绿色"理想区"色带（前排 0.5–1.2m，随攻手/风格自动切换后场区）
- **击球高度尺**：目标点竖直标尺（地面→击球点），带三个刻度：网顶 2.43 / 攻手摸高（虚线横环 + 标签"摸高 3.20m"）/ 当前击球高度标签"击球 2.85m"，超摸高变红
- **弧顶标尺**：弧顶处"网上 +1.0m"浮动标签，按风格标准域着色
- **人球节奏标签**：攻手头顶浮动"人球 +0.21s ✓ / 球先到 −0.3s ✗ / 等球 0.8s ⚠"；并绘制攻手助跑虚线（站位→起跳点）与起跳圈
- **过网余量尺**：击飞线与网面交点处"过网 +0.08m"标签，红/黄/绿

### 2. 质检面板（ControlPanel 新 section"传球质量检查"）
预检清单式列表：状态图标（✓/⚠/✗）+ 指标名 + 实测值 + 标准区间 + 一句改进建议；顶部显示综合质量分（0–100）。规则违例项为红色置顶。参数/站位任何改动实时刷新。

### 3. 目标环联动
击球点目标环颜色跟随综合等级（红时闪烁加剧），3D 标签与面板同源计算，保证一致。

## 三、技术实现
- **`logic/quality.ts`**（纯函数，可单测）：`evaluateQuality(ctx)` 输入 {传球解, 击飞解, 攻手, 风格(来自选中方案), 摸高表} → 输出 `items[]`（key/名称/实测文案/标准文案/等级/建议）+ 综合分 + 总等级。摸高与等球上限按角色/风格内置常量表
- **`scene/QualityOverlays.tsx`**：5 类浮动图例组件（Html 标签统一样式 chip；Line2 画尺线/助跑虚线/理想区色带；受 `uiStore.showQuality` 控制）
- **`useQuality()`**（useSolution.ts 内共享 hook）：面板与 3D 用同一 memo 结果
- **store**：uiStore 加 `showQuality`（默认开）；ControlPanel 加"显示质量图例"复选框
- **TargetHandle**：环色接质量等级
- **测试**：quality.ts 各band 边界、违例判定（自由人/后排前区攻）、人球 Δ 计算
- **文档**：CONTRACTS.md 增补指标定义；README 更新功能清单

## 四、实施步骤
1. quality.ts + 单测
